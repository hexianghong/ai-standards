# 公司规约治理

公司强制控制适用于已接入的项目及指定环境，由安全与平台负责人管理。项目补充规则可以细化默认约定，触及强制控制的例外需要范围、批准角色、生效与到期时间及补偿措施。

客户端系统指令、实际权限和原生加载机制决定运行结果。提示词规则记录工作意图，强制控制必须关联执行点和实测证据。CI 控制记录提交与发布阶段的验证结果，运行时限制由运行时系统执行。

公司默认规则包括保留无关改动、按任务验证、使用项目真实命令。项目可以增加验证命令、业务边界及交付要求。用户个人偏好和知识库路径进入用户配置。任务角色随请求传入。

发布变更由领域负责人评审，强制控制变更由安全负责人评审。版本与内容摘要固定，修改后生成新版本。发布者身份通过公司可信渠道验证，摘要用于内容完整性验证。

反馈记录项目、规则版本、客户端、脱敏复现条件和预期。经用户授权上报后，由负责人分流为规则、技能、工具或项目改进，附回归场景并随版本发布。例外到期由相应权限系统撤销。
