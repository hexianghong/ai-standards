# 公司级总控验收要求

状态按证据判定。AC-11、AC-12、AC-13 的公司环境证据必须由实际试点产生。

- AC-01 稳定入口。给定目标环境，执行对应场景后，干净检出包含受跟踪入口，通用规则使用仓库相对路径，项目规则覆盖范围明确。
- AC-02 任务路由。给定目标环境，执行对应场景后，咨询、代码变更、排障按触发条件加载技能，公司基线与项目默认规则区分。
- AC-03 角色隔离。给定目标环境，执行对应场景后，激活角色不写共享项目规则，浏览器会话分别保存角色并在请求中传入。
- AC-04 产物构建。给定目标环境，执行对应场景后，相同输入构建相同文件摘要，发布文件清单完整，拒绝链接和非法路径。
- AC-05 版本安装。给定目标环境，执行对应场景后，明确版本和客户端，预览无项目写入，安装验证发布摘要并固定版本。
- AC-06 项目保护。给定目标环境，执行对应场景后，保留已有普通指令文件正文，拒绝未知链接和技能冲突，重复安装幂等。
- AC-07 事务恢复。给定目标环境，执行对应场景后，互斥安装，多文件操作有持久日志，异常恢复不覆盖后续人工修改。
- AC-08 诊断回滚。给定目标环境，执行对应场景后，诊断报告文件漂移、版本及未验证能力，回滚保留备份并校验当前文件。
- AC-09 兼容入口。给定目标环境，执行对应场景后，旧初始化调用可用，新参数进入新安装器，旧链接迁移有明确诊断。
- AC-10 自动回归。给定目标环境，执行对应场景后，构建安装升级回滚、摘要错误、路径逃逸、重复安装、并发和冲突场景自动执行。
- AC-11 客户端实测。给定目标环境，执行对应场景后，公司实际 Codex 和 Antigravity 各在新会话中证明加载版本与技能。
- AC-12 强制控制。给定目标环境，执行对应场景后，凭据、生产写入、跨项目访问分别有执行点、负责人和允许拒绝实测证据。
- AC-13 推广反馈。给定目标环境，执行对应场景后，反馈携带规则版本且脱敏，版本发布经过负责人评审，试点完成升级回滚演练。
