# 改动与验证报告

本次修改了全局规约、敏捷流程、工作台规格生成和看板接口，以及项目初始化、规格检查、终端看板和归档脚本。

- AC-01 通过：在带有旧 doc/ 目录的临时工作区启动真实 HTTP 服务。两个卡片各保存、列出和读取四份同名文档，按完整路径关联各自资产。重复生成已有规格返回 HTTP 409，原文档保留。
- AC-02 通过：在预置 /docs/specs/ 忽略规则的临时 Git 仓库运行 init-project.sh 和 init-project.sh --update。git check-ignore 验证需求四份文档可跟踪，旧平铺文档和临时文件仍被忽略。重复初始化得到相同规则。
- AC-03 通过：工作台 API 对缺少实施方案、引用无效和缺少完成证据返回 HTTP 409。补齐任务和证据后可完成流转。通过 .agents/tools/update-kanban.sh 验证终端看板也会拦截缺少报告的完成请求。
- AC-04 通过：通过 .agents/tools/archive-specs.sh 和工作台集成测试验证归档只包含目标需求的四份文档，第二次执行报告归档已是最新。另一个需求仍可被独立读取，且缺少证据时归档失败。
